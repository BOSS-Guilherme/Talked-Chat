## 📖 Sobre

O **Talked-Chat** é um exemplo de aplicativo de bate-papo que permite a **comunicação entre dois usuários** por meio de **conversas em tempo real**.

Foi pensado para ser uma base **clara e fácil de entender**, ideal para quem quer aprender como funciona a troca de mensagens instantâneas ou usar o projeto como ponto de partida para algo maior.

## ✨ Funcionalidades

- 💬 Troca de mensagens em tempo real entre dois usuários
- ⚡ Entrega instantânea, sem precisar atualizar a página
- 🧑‍🤝‍🧑 Conversa direta entre duas pessoas
- 🎨 Interface simples e fácil de usar

## ⚙️ Como usar localmente

1. Clone o repositório:

```
git clone https://github.com/BOSS-Guilherme/Talked-Chat.git
cd Talked-Chat
```

2. Instale as dependências:

```
npm install
```

3. Inicie o projeto:

```
npm start
```

4. Abra o endereço indicado no terminal em dois navegadores diferentes para simular a conversa entre dois usuários.
